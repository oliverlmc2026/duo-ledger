# Duo Ledger 雙人記帳

手機優先的記帳 PWA，單一幣別 £ GBP，繁中／English 可切換。可以離線使用，資料只存在你自己的手機。

**網址：** https://oliverlmc2026.github.io/duo-ledger/

## 安裝到手機

- **iPhone：** 用 Safari 開上面的網址，按分享鍵，選「加入主畫面」。
- **Android：** 用 Chrome 開網址，選單裡按「安裝應用程式」或「加到主畫面」。

加到主畫面之後，**請只用主畫面那個圖示記帳**。在 iPhone 上，Safari 和主畫面 App 的資料是分開的，兩邊記的帳不會互通。

第一次開啟時輸入你的暱稱。暱稱是同步時辨認身份用的，之後不能改，請兩個人用不同的暱稱。

## 個人記帳

在「記帳」分頁按右下角的 **+**：

1. 選「支出」或「收入」。
2. 填金額、分類、日期、備註（商家名稱）。
3. 按「儲存」。

點任何一筆可以修改或刪除。上方箭頭可以切換月份。

分類在「設定」分頁管理，內建飲食、交通、購物、住家、娛樂、其他（支出）和薪資、其他（收入），可以改名，也可以新增。

「統計」分頁顯示當月的分類佔比，以及最近六個月的支出趨勢。**統計只計算個人帳目，不含共同帳。**

## 共同記帳

兩個人各自記下自己墊付的款項，永遠 50/50 平均分攤。

1. 按 **+** 時勾選「共同帳（50/50）」。
2. 在「誰墊付」選擇是你還是伴侶。
3. 「共同」分頁會隨時顯示誰要補多少給誰。

金額全程用整數便士計算。總額除以 2 有餘數時，多出的那一便士由要補錢的一方承擔。例如你墊付 £10.01、伴侶墊付 £2.00，總共 £12.01，伴侶要補你 £4.01。

「誰墊付」要先和伴侶同步過一次，才能選到對方（見下一節）。

### 結算

兩人對好帳之後，在「共同」分頁按「結算」。這一期會封存成歷史紀錄，並開始新的一期。結算結果也會透過分享碼傳給對方，所以兩部手機的歷史紀錄會一致。如果兩人都按了結算，只要結算的帳目相同，就不會出現重複的紀錄。

## 和伴侶同步（分享碼）

資料不經過任何伺服器。兩個人用「複製文字碼」，透過 WhatsApp 等軟體互傳。

**你傳給伴侶：**

1. 開「共同」分頁，按「複製我的碼」。
2. 把這段文字貼到 WhatsApp 傳給伴侶。

**你收到伴侶的碼：**

1. 複製伴侶傳來的整段文字。
2. 在「共同」分頁的「貼上對方的碼」輸入框貼上，按「匯入」。
3. 畫面會顯示更新了幾筆。

雙方都要做一次，帳才會一致。之後每次想對帳，就重複這個流程。

同步的規則：

- 第一次匯入時，App 會自動認出對方的暱稱，並把對方設為共同記帳對象。
- 每筆帳目都有唯一 ID，重複匯入同一個碼不會出現重複的帳。
- 同一筆帳在兩邊都被修改時，以最後修改的版本為準。
- 刪除也會同步，已刪除的帳不會因為匯入舊碼而復活。
- 分享碼**只包含共同帳和結算紀錄**，不包含你的個人帳目和分類。
- 匯入自己的碼，或另一位陌生人的碼，會被拒絕。

## 備份與還原

備份包含**全部資料**：個人帳目、共同帳、結算紀錄、分類和伴侶資料。換手機、重裝 App 或刪除主畫面圖示之前，請先備份。

**備份：** 「設定」分頁的「備份」區：

- 「複製備份碼」，貼到自己的備忘錄或雲端筆記保存。
- 「下載備份檔」，得到一個 `duoledger-backup-日期.txt`。

**還原：**

- 在新手機第一次開啟的歡迎畫面，或在「設定」分頁，貼上備份碼按「還原」，或選「從檔案還原」。
- 還原是**合併**而不是覆蓋：每筆帳目保留較新的版本，所以重複還原不會產生重複的帳。
- 備份屬於另一位使用者（暱稱不同）的話會被拒絕。

備份碼是純文字，**沒有加密**，裡面是你的全部帳目，請當成私人資料保管。

## 離線與更新

第一次連網開啟後，App 會把檔案存在手機上，沒有網絡也能用。

有網絡時，每次開啟都會先拿最新版本。我們更新網頁之後，下次連網開啟就會換成新版。iPhone 的主畫面 App 要**完全關掉再重新打開**才會載入新版。

## 開發

沒有建置步驟，也沒有任何外部套件。

| 檔案 | 用途 |
|---|---|
| `index.html` | 介面、中英文字串、SVG 圖表 |
| `core.js` | 金額解析、合併、結算、分享碼和備份 |
| `core.test.js` | `core.js` 的測試 |
| `sw.js` | Service worker，負責離線快取 |
| `manifest.webmanifest`、`icon*` | 安裝到主畫面所需 |

跑測試：

```bash
node --test core.test.js
```

本機預覽（service worker 需要 localhost 或 HTTPS）：

```bash
python3 -m http.server 8000
```

然後開 http://localhost:8000 。部署是 GitHub Pages，從 `main` 分支根目錄發佈，push 之後約一分鐘更新。
